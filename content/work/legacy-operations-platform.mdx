## Context

This illustrative example describes a common modernization shape: an important internal application has become hard to change, test, and operate.

## Approach

The first phase would map the architecture, add automated checks around critical workflows, improve release confidence, and identify slices for refactoring or migration.

## What this example demonstrates

This is an illustrative modernization pattern, not a client case study. The approach is to make critical workflows testable and choose migration slices based on evidence rather than rewrite momentum.
