## Assessment scope

An assessment looks at architecture, code quality, data stores, integrations, deployment flow, observability, dependency age, security concerns, and where change is slow or risky.

## Modernization plan

The output should be a modernization plan: immediate risk reductions, candidate refactors, migration options, and work that should wait until the business case is clearer.
