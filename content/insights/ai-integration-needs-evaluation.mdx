## Evaluation is product work

An AI feature is not done when the first prompt works. Teams need representative examples, expected behavior, known failure cases, quality thresholds, and a plan for drift.

## Questions to answer before release

- Does the model have the right context and permission boundaries?
- Are users told when output is uncertain or needs review?
- Can the team inspect failures without exposing sensitive data?
- Is there a fallback path when the model should not decide?
